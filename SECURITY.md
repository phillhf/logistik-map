# Sicherheit / Security

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils [neueste Version](https://github.com/phillhf/logistik-map/releases/latest).
Ein Update spielt ein Administrator unter *Einstellungen → Updates* auf Knopfdruck ein.

## Sicherheitslücke melden

Bitte **kein öffentliches Issue** anlegen. Stattdessen vertraulich über GitHub melden:
**[Security → Report a vulnerability](https://github.com/phillhf/logistik-map/security/advisories/new)**.

Hilfreich sind: betroffene Version, Schritte zum Nachstellen und die mögliche Auswirkung.
Meldungen werden so schnell wie möglich bearbeitet. Nach der Korrektur erscheint ein Release mit
Hinweis im Änderungsprotokoll, auf Wunsch mit Nennung der meldenden Person.

Was Logistik Map zur Sicherheit tut (Anmeldung, Rechte, Daten, Updates), steht in
[docs/IT.md](docs/IT.md).

---

## Reporting a vulnerability (English)

Please do **not** open a public issue. Report it privately via
**[Security → Report a vulnerability](https://github.com/phillhf/logistik-map/security/advisories/new)**,
including the affected version, steps to reproduce and the possible impact. Fixes are released as
a new version; only the latest version receives security fixes.
